Este programa fue creado como TFG para el grado en ingeniería informática de la UNED. Es una demo, no un programa completo.\
Disponible únicamente en castellano.

## Descripción
"APJ, una aplicación para aprender a programar jugando" es un videojuego orientado a niños y niñas que permite a los usuarios la creación de programas sencillos mediante los cuales controlar el comportamiento de Bit, 
un robot que se moverá e interactuará con un escenario virtual. Para la creación de dichos programas se usa la programación por bloques, también conocida como programación visual.

## Modos de juego
### Modo juego
Aquí el usuario podrá acceder a distintos minijuegos en los que tendrá que resolver diversos puzles mediante la creación de programas. Cada minijuego cuenta con un tutorial.

- Alcanza el objetivo: el jugador deberá mover a Bit hasta un punto concreto del escenario evitando que choque contra los obstáculos.

### Modo libre
Aquí el jugador podrá experimentar libremente con todos los comandos disponibles en el juego. Además, podrá cambiar el aspecto del robot y modificar el escenario colocando nuevos suelos, obstáculos u objetivos. A parte de usar los elementos de edición disponibles de forma predeterminada, los usuarios también podrán crear los suyos propios cargando imágenes almacenadas en su ordenador.
