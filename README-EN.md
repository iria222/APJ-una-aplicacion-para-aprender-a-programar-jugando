This program was created as the final project for the Computer Science degree at UNED.  It is a demo, not a full program.<br/>
Only available in Spanish.

## Description
"LPP, an application to learn how to program by playing", is a video game aimed at children that allows users to create simple programs to control Bit's behaviour, a robot that moves around a virtual stage and interacts with it. Block coding, also known as visual programming, is used to create the aforementioned programs.

## Game modes
### Playing mode
Here, players will have access to several minigames where they will have to solve different puzzles by creating programs. Each minigame has its own tutorial.

### Free mode
Here, players will be able to freely experiment with all the available commands in the game. Additionally, they will have the ability to change the robot's appearance and to modify the stage by adding new floors, obstacles and goals. Apart from using the default modification elements, users can also create their own by uploading images saved on their computer.

## Used tools
